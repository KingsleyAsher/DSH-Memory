# DSH Memory 1.0.12

面向 DeepSeek Harness 的长期记忆插件。将值得复用的偏好、约束和项目事实保存为带来源的记录，在后续对话中按需召回，并支持更正、撤回、人工管理与可选知识库联动。

## 插件能做什么

- **主动保存**：主模型使用 `memory_submit` 提交记忆；程序检查来源、作用域和状态变更。明确的记忆请求另有确定性捕获路径。
- **按需召回**：在会话步骤前查询当前项目及全局记录，以有预算的证据补充上下文，不固定注入全部记忆。
- **同次压缩**：对支持的官方 Basic 压缩引擎，在原有压缩调用中同时生成摘要与记忆，不新增全文提炼模型调用。自定义压缩引擎需要自己的适配器。
- **详情与更新**：在“记忆 → 详情”查看运行版本、手动检查更新和 GitHub/Gitee/GitCode 仓库；原有自动检查与自动安装继续工作。
- **管理与复核**：提供记忆列表、关系视图、手动新增和删除，以及低置信度候选的接受、编辑后接受或拒绝。关系连线不等于事实相互证明。
- **作用域**：所有 Agent 预设共用记忆。全局记忆跨项目可用；项目记忆仅随对应项目激活，切换项目或预设不会删除记录。只有明确清理才删除。
- **可选共享**：其他兼容组件存在并连接时共享；未安装时独立运行。知识库来源记录只读，原文和权限由知识库维护。

## 安装

当前声明兼容 DSH **0.2.1-rc.5**、Cordis **~4.0.5**。需要 Python **3.11+** 和 NumPy；验证环境使用 Node 24。先为插件使用的 Python 安装依赖：

```sh
python -m pip install numpy
```

在 DSH 插件管理器中添加以下安装源，或选择下载后的本地 `.tgz` 文件：

```text
https://raw.githubusercontent.com/KingsleyAsher/DSH-Memory/main/dist/local-dsh-memory-1.0.12.tgz
```

启用后打开左侧“记忆”（窄窗口可能收入“更多”）或会话中的记忆视图。宿主要求重新加载时，完全退出含托盘进程后重启。现有预设在创建或恢复智能体时接入记忆能力；也保留独立“DSH 记忆”预设。

## 数据与隐私

运行数据保存在用户自己的本地 SQLite 存储中。插件复用当前会话的主模型，因此送入会话的记忆证据遵循该模型的处理位置；选择云端模型时，这些证据会随上下文发送给该提供方。插件不启动独立提炼模型、不自动下载模型、不启用后台云端向量请求。

公开源码和安装包不包含开发者的记忆、聊天、知识库正文、账户凭据、本机路径、日志或研究运行数据。发布扫描说明见 [PUBLICATION.md](PUBLICATION.md)。

## 验证与限制

本版本提供合成数据的作用域、待确认候选及显式记忆测试，包文件清单与摘要也可核验。此前联动验证使用隔离工作进程和合成知识库，不代表真实个人资料或长期模型准确率测试。1.0.12 发布检查结果见 [发布清单](release-manifest.json)。

图像、音频和附件原文提取不在本插件内。自定义压缩引擎、复杂跨项目指代和任意长上下文质量尚无普遍保证。宿主关闭后只保留待办，不会继续后台推理。更新遵循[版本与更新规则](VERSIONING.zh-CN.md)：所有较新版本自动安装，包括跨主版本和预览版，状态仅在页内显示，无更新弹窗。此版本不提供跨设备同步。

## 1.0.8 更新与边界

本次发布汇总 1.0.5 之后尚未公开的修复，以及 2026-11-07 的记忆重试和关系网文字调整。

- 记忆提交被拒绝、部分保存或抛出错误后，下一步提供新的批次合同；合同内容不变也不复用已经提交的回答。过期批次调用同样触发刷新。仍禁止改写旧批次的首次回答，保留原文和跨会话校验。
- 路径字段只接受原文中的路径字面量；报错提示明确说明，应将默认位置和适用条件等完整约定另存为规则。仅工具回执 state=saved 且 can_confirm_saved=true 时确认保存。重启不会保证模型已重新提交或保存成功。
- 关系网文字固定在节点旁，遮挡时虚化，遮挡解除后恢复。移除标签避让选位及牵引线，避免文字在重绘时跳动。保留节点旋转、缩放和选择交互。
- 自动记忆所有者跨预设及工具服务域工作。pure 预设、会话 memoryEnabled=false 或 excludedPresets 中的预设不注入、不采集、不绑定记忆工具，并使用原压缩路径；已有记忆仍保留。
- 增加可选微信会话作用域和聊天表达习惯项目存储接口。聊天风格档案标为模型推断，不作为全局事实；仅搭配支持接口的微信插件使用。此包不包含微信插件，也不训练模型。

兼容要求以 package.json 的 peerDependencies 为准：DSH 及相关官方包 0.2.1-rc.5、Cordis ~4.0.5。旧宿主不保证兼容。

发布检查使用虚构数据和隔离的本地 Python 工作进程，覆盖拒绝后新批次重试、旧回答不可改写、纯净排除、会话隔离及续步召回，并检查 JavaScript 语法、安装包往返和公开内容边界。未使用私人记忆库、真实聊天或付费模型。没有验证安装本发布包后完整重启的真实宿主表现，关系网的实际视觉效果也尚未人工验收。精确构建号、摘要和测试数量见 release-manifest.json。

通过 DSH 插件管理器安装 local-dsh-memory-1.0.8.tgz。保存当前工作后完全退出宿主（包括托盘）并重新打开，在记忆详情中确认版本 1.0.8。失败记忆可在原会话要求重新保存，并核对工具成功回执及记忆列表；不能只以助手口头复述判断入库。

## 1.0.9 加载优化

修复打开记忆管理页面时，本地记忆需要等待知识库联动读取完成的问题。本地列表立即返回，联动记录在后台取得完整快照后补入；新增加载状态，联动失败时仍可查看本地记录。

同一会话合并并发联动请求，最多保留八个会话的管理页快照，快照三十秒到期。联动变更通知和服务切换会使缓存及在途旧结果失效，避免旧内容重新出现。前端合并重复刷新，并保留内容未变时的列表身份。缓存仅用于管理页；正常对话召回仍读取实时快照。

验证：浏览器隔离页面使用虚构记录与固定三秒联动延迟，本地记录显示时间从 3489 毫秒降到 96 毫秒；这是该场景的一次测量，不是实际宿主耗时承诺。联动记录后续加载、项目范围切换通过，未发现页面运行错误。新增测试覆盖请求合并、会话隔离、缓存失效、过期、失败、不完整快照和服务移除；发布检查继续覆盖已有回归、包内容与公开边界。未发布私人数据库、聊天或本机测试资料。真实宿主安装并完整重启后的耗时未验证。

兼容要求沿用 1.0.8，以 package.json 的 peerDependencies 为准。通过 DSH 插件管理器安装 local-dsh-memory-1.0.9.tgz，完全退出宿主（含托盘）再打开，并在记忆详情中确认版本 1.0.9。构建号、摘要与测试数量见 release-manifest.json。

## 1.0.10 宿主兼容修复

修复升级 DSH 后插件被精确版本依赖阻止加载的问题。DSH 与所需官方包现在接受 0.2.1（从 rc.5 起）和 0.2.2（从 rc.1 起）系列，Cordis 接受 ~4.0.5 或 ~4.1.0；不自动放行 0.2.3 或 Cordis 4.2。

分别使用官方 0.2.1-rc.5 / Cordis 4.0.5 和本机安装归档中的 0.2.2-rc.1 / Cordis 4.1.0 运行隔离检查。两组均覆盖真实插件装载、Agent 工具调用、持久化、同次压缩、跨会话召回、项目隔离、工作进程重启与旧待办恢复；模型输出使用离线桩，不是付费或真实模型验证。新版独立的原生工具执行器由测试宿主正常加载，记忆插件不替换用户的执行器。

记忆数据目录与数据库格式保持不变，升级保留既有记录；纯净模式排除、严格保存回执和管理页面分阶段加载继续保留。新增可复用的双宿主检查脚本。精确检查结果和安装包摘要见 release-manifest.json。真实桌面进程完整重启后的运行状态仍需确认。

通过 DSH 插件管理器安装 local-dsh-memory-1.0.10.tgz，完全退出 DSH（含托盘）再打开，在记忆详情中确认 1.0.10。本版修正兼容声明，不依赖关闭宿主兼容检查或添加强制豁免。
