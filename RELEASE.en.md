# DSH Memory 1.0.14

The plugin runs independently. Integrations can use the versioned interface for global records and conversation style profiles. Linked entries remain owned by their knowledge documents.

The Memory page applies changes on notification and reuses its cache while connected. Older hosts and interrupted subscriptions use revision checks. Deleting a record no longer blocks later additions.

Pair with Knowledge Base 2.5.10. Validation uses isolated fixtures. Fully exit DSH, including the tray process, and reopen after installing.
