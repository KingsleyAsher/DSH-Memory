# DSH Memory 1.0.1

2026-11-04. Adopts the knowledge-base version ordering and update policy. Same-major stable updates install automatically; major and preview switches remain manual. Checks run after approximately 15 seconds and every six hours. All update status stays inline without popups.

Downloads undergo package identity, version, size, SHA-256 and archive-path checks before host-managed installation. Unknown installation receipts are not automatically retried. GitHub is the only configured source. See VERSIONING.en.md. Release checks use synthetic data, without live inference, private memories or installation into the daily host.
