# DSH Memory 1.0.4

Memory → Details now shows the running version, manual update checks, check time, per-source status, every configured repository and issue reporting. Startup and six-hour automatic checks and eligible host-managed automatic installation remain enabled.

Unsuccessful or partial writes fail the tool explicitly. Confirmation requires a saved receipt. Unambiguous punctuation-only differences restore the literal source, and a single missing assertion reference may be bound deterministically. Changed content or numeric meaning remains rejected. Original responses are immutable; corrected retries use a new batch.

Agent presets share memory. Global records apply across projects; project records activate only for their project. Switching presets, windows or projects no longer erases records. Same-project legacy window scopes remain accessible, while explicit clearing still removes project records. The initial view shows global memory.

Synthetic core tests, JavaScript checks, updater checks and archive round trips validate this release. Details and automatic installation calls were tested in an isolated component with synthetic responses and a simulated host installer. This release was not installed in the user's host and was not evaluated with live model calls. It does not guarantee perfect model classification or truthful model wording in every future response. Similar records across scopes are not automatically merged.

Mirrors can lag; conflicting hashes, sizes or build identifiers block installation. If host hot reload reports a missing root Include, package files may already be installed; fully restart the host and verify its running version. Do not manually insert an Include into cordis.yml based only on that error.
